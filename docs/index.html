Don't Touch Me

A tiny interactive comedy about a blob that would like a little personal space.

How to play

Tap the blob. Leave it alone to let it relax and fall asleep.

Support

Report an issue or ask a question. The issue tracker is public; please do not post personal or sensitive information. GitHub sign-in is needed to submit an issue, but the game has no accounts.

Privacy policy

This informational site contains no analytics, forms, external fonts, or scripts. Hosting and any GitHub support interaction are covered by GitHub's own policies.
