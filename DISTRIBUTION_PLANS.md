# Distribution plan

The canonical 25-platform registry is [release/distribution/platforms.json](release/distribution/platforms.json). Shared descriptions, publisher identity, assets, content information, notices, release notes and free pricing live in [release/catalog/game.json](release/catalog/game.json).

Follow [release/RELEASE_SYSTEM.md](release/RELEASE_SYSTEM.md) to create local format-based builds and per-platform upload checklists. Publication remains not_published until separately authorized and verified with an actual live URL and version. Local builds and source pushes never imply publication.

This release has no payments, donations, purchases, ads or currency integration. Historical plans remain available in Git history.
